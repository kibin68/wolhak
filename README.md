# 월학국민학교 · 우리의 1981

월학국민학교 제26회 졸업생의 실제 졸업앨범으로 만든 추억 웹사이트입니다.
1980학년도 졸업기념 앨범의 표지에 적힌 1981년을 함께 반영했습니다.

## 이용 방법

- 첫 화면의 단체사진을 누르면 크게 볼 수 있습니다.
- ‘졸업앨범’의 차례에서 원하는 사진을 선택하세요.
- ‘이전 장’과 ‘다음 장’으로 10장을 순서대로 넘겨볼 수 있습니다.
- 확대 창에서는 사진을 한 번 더 누르면 확대됩니다. 다시 누르면 원래 크기로 돌아옵니다.
- 키보드의 왼쪽·오른쪽 화살표로 확대 창의 사진을 넘기고, Esc로 닫을 수 있습니다.
- 휴대전화에서는 앨범 차례를 좌우로 밀어 선택할 수 있습니다.

## 현재 상태

사용자의 공개 승인에 따라 GitHub Pages로 게시하는 사이트입니다.
사이트 주소: https://kibin68.github.io/wolhak/
GitHub Pages에 공개 게시하면 동창생 외의 사람도 사진과 앨범 속 이름을 볼 수 있습니다.
원래 사이트는 Git 기록의 최초 커밋에 보존되어 있습니다.

## 파일 구성

- `index.html`, `assets/`, `album/`: GitHub Pages에서 바로 사용할 완성본
- `website-source/`: 이후 디자인과 기능을 수정할 수 있는 원본 소스
- 사진 10장은 사용자가 지정한 파일을 내용 변경 없이 복사했습니다.
- 원본 사진은 덮어쓰거나 삭제하지 않았습니다.

## 제작 소스 실행

Node.js 22.13 이상과 pnpm을 사용합니다.
`website-source`에서 의존성을 설치한 뒤 `pnpm dev`로 미리보기,
`pnpm typecheck`로 형식 검사, `pnpm build`로 게시용 파일을 생성합니다.
완성 파일은 `website-source/pages-dist/`에 생성됩니다.
새 완성본을 저장소 맨 위에 반영하고 GitHub Pages로 게시할 수 있습니다.

게시 환경에서 별도 서버, 데이터베이스, 유료 API는 사용하지 않습니다.
